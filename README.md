# 🤖 Telegram Support Bot

Телеграм-бот для поддержки клиентов с живыми операторами. Система позволяет клиентам отправлять обращения, а операторам - отвечать на них в режиме реального времени.

## 🎯 Основные возможности

### Для клиентов:
- ✉️ Отправка текстовых сообщений
- 📎 Отправка фото и документов
- ⏳ Автоматическая постановка в очередь
- 📝 История всех обращений

### Для операторов:
- 👥 Поддержка нескольких операторов одновременно
- 📋 Просмотр очереди ожидающих обращений
- 💬 Управление активными диалогами
- 📊 Статистика по обработанным обращениям
- 🟢 Статус онлайн/оффлайн
- ⚖️ Автоматическая балансировка нагрузки

## 🏗️ Архитектура системы

```
┌─────────────┐         ┌─────────────┐
│   Клиент    │────────▶│   Telegram  │
│             │         │     Bot     │
└─────────────┘         └──────┬──────┘
                               │
                               ▼
                        ┌──────────────┐
                        │  Диалоговая  │
                        │   система    │
                        └──────┬───────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                ▼                ▼
      ┌───────────┐    ┌───────────┐   ┌───────────┐
      │ Оператор 1│    │ Оператор 2│   │ Оператор N│
      └───────────┘    └───────────┘   └───────────┘
```

### Состояния диалога:
1. **waiting** - ожидает назначения оператора
2. **active** - назначен оператор, диалог активен
3. **closed** - диалог завершен

### База данных:
- **User** - клиенты
- **Operator** - операторы поддержки
- **Conversation** - диалоги между клиентами и операторами
- **Message** - все сообщения в системе

## 🚀 Установка и настройка

### 1. Установка зависимостей

```bash
npm install
```

### 2. Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте токен бота

### 3. Получение Telegram ID

Чтобы получить ваш Telegram ID:
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Бот вернет ваш ID

### 4. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# База данных (SQLite по умолчанию)
DATABASE_URL="file:./dev.db"

# Telegram ID операторов (через запятую)
OPERATOR_IDS=123456789,987654321,555666777

# Telegram ID администратора
ADMIN_ID=123456789

# Максимум активных чатов на оператора
MAX_CHATS_PER_OPERATOR=5
```

### 5. Инициализация базы данных

```bash
npm run prisma:generate
npm run prisma:migrate
```

### 6. Запуск бота

Для разработки:
```bash
npm run dev
```

Для продакшена:
```bash
npm run build
npm start
```

## 📱 Использование

### Для клиентов

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Напишите ваш вопрос
4. Дождитесь ответа оператора

### Для операторов

После запуска бота, операторы получат специальное меню с командами:

#### Команды:

- `/start` - Запуск панели оператора
- `/queue` или 📋 - Посмотреть очередь ожидающих
- `/active` или 💬 - Мои активные диалоги
- `/stats` или 📊 - Моя статистика
- `/online` или 🟢 - Войти в сеть
- `/offline` или 🔴 - Выйти из сети
- `/done` - Завершить текущий диалог
- `/cancel` - Отменить режим ответа

#### Рабочий процесс:

1. **Войти в сеть**: `/online`
2. **Получить уведомление** о новом обращении
3. **Взять в работу**: нажать кнопку "✅ Взять в работу"
4. **Отвечать клиенту**: просто пишите сообщения
5. **Завершить диалог**: `/done` или кнопка "✅ Закрыть диалог"

#### Режимы работы:

**Активный режим:**
Когда вы берете диалог в работу, все ваши сообщения автоматически отправляются клиенту.

**Режим выбора:**
Если у вас несколько активных диалогов, используйте кнопку "✉️ Ответить" для переключения между ними.

## 📊 Система распределения

Бот автоматически распределяет обращения между операторами:

1. **Балансировка нагрузки**: Новые обращения назначаются оператору с наименьшим количеством активных диалогов
2. **Лимиты**: Каждый оператор может обрабатывать до N активных диалогов (настраивается в `.env`)
3. **Статус**: Обращения назначаются только онлайн операторам
4. **Очередь**: Если все операторы заняты, обращения остаются в очереди

## 🔐 Безопасность

- Telegram ID операторов жестко заданы в конфигурации
- Доступ к командам операторов защищен проверкой ID
- База данных изолирована от прямого доступа
- Все сообщения сохраняются в базе данных для аудита

## 📈 Масштабирование

### Для большой нагрузки:

1. **Замените SQLite на PostgreSQL**:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/supportbot"
   ```

2. **Обновите schema.prisma**:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```

3. **Запустите миграцию**:
   ```bash
   npm run prisma:migrate
   ```

### Для распределенной системы:

- Используйте Redis для хранения оперативного состояния
- Настройте очередь сообщений (RabbitMQ, Kafka)
- Разделите операторов по группам/категориям

Все ошибки выводятся в консоль. Для продакшена настройте логирование в файл:

```typescript
// Добавьте в src/index.ts
import fs from 'fs';

const logStream = fs.createWriteStream('bot.log', { flags: 'a' });
console.log = (...args) => {
  const message = args.join(' ');
  logStream.write(`${new Date().toISOString()} - ${message}\n`);
};
```
